# Scripts

The active site no longer depends on scripts in this directory.

`archive/` contains one-off maintenance scripts from the period when the
entire site, CSS, and interview data lived inside `index.html`. They are kept
only as project history and **should not be run against the current modular
layout**.

Current files live in:

- `/interviews/` for interview/profile data
- `/js/` for application, editor, and press-rendering logic
- `/css/` for styles
- `/pictures/` for image assets
